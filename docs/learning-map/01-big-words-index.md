## AI 時代的新詞

AI 影像工具更新很快，這裡只收跨工具通用的大詞；工具名稱會換，這些概念不會。

| 大詞                                        | 是什麼                           | 一眼就認得的樣子             | 細節              |
|---------------------------------------------|----------------------------------|------------------------------|-------------------|
| Prompt 提示詞                               | 用文字描述想要的畫面             | 「描述公式」七欄就是好提示詞 | 地圖 · 描述公式   |
| Negative Prompt 反向提示詞                  | 寫明不要什麼                     | 「不要文字、不要變形的手」   | 地圖 · 描述公式   |
| Text-to-Video 文字生成影片                  | 從一段文字生成影片               | 輸入描述得到 5 秒鏡頭        | 語彙三 · 鏡頭     |
| Image-to-Video 圖片生成影片                 | 讓一張靜態圖動起來               | 插畫裡的頭髮與雲開始飄       | 語彙一 · 運動來源 |
| First ／ Last Frame 首尾幀控制              | 指定開頭與結尾畫面，讓 AI 補中間 | A 圖變到 B 圖的過程          | 語彙一 · 運動來源 |
| Video-to-Video 影片轉影片                   | 保留原影片動作、換風格           | 實拍變成黏土動畫             | 語彙五 · 媒材     |
| Style Transfer 風格轉換                     | 把一種畫風套到影像上             | 照片變水彩                   | 語彙五 · 媒材     |
| Camera Control 鏡頭控制                     | 指定 AI 影片的鏡頭運動           | 「緩慢推進加環繞」           | 語彙三 · 鏡頭     |
| Motion Transfer 動作轉移                    | 把一段動作套到另一個角色         | 讓插畫人物跳同一支舞         | 語彙一 · 運動來源 |
| Lip Sync 對嘴                               | 讓嘴型對上聲音                   | 照片人物開口說話             | 語彙三 · 聲音     |
| Character Consistency 角色一致性            | 同一角色在不同鏡頭長得一樣       | 系列短片的同一主角           | 語彙五 · 類型     |
| Frame Interpolation 補幀                    | 在兩格之間生成中間格             | 30 fps 補成 60 fps、超慢動作 | 語彙一 · 時間     |
| Upscaling 超解析                            | 把低解析度放大並補細節           | 720p 變 4K                   | 語彙四 · 規格     |
| Segmentation ／ AI Rotoscoping 自動去背     | 自動把主體從背景分離             | 人物一鍵去背                 | 語彙二 · 後製     |
| Depth Estimation 深度估計                   | 從平面圖推算前後距離             | 老照片變 2.5D 視差           | 語彙三 · 鏡頭     |
| Inpainting 局部重繪 ／ Outpainting 畫面延伸 | 改掉畫面一部分，或把畫面往外長   | 直式畫面延伸成橫式           | 語彙二 · 後製     |
