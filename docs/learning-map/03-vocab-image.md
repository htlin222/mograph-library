# 語彙二：畫面

這頁管「畫面上被改變的是什麼、長什麼樣」，對應地圖的三（視覺對象）。

## 形狀與圖形

2D 向量圖形的動態手法，是品牌、UI、解說動畫最常用的一組詞。

| 術語                           | 意思                                 | 描述範例                               |
|--------------------------------|--------------------------------------|----------------------------------------|
| 路徑描繪 Draw-on ／ Trim paths | 線條從頭畫到尾                       | 「logo 外框 0.8 秒描繪出來」           |
| 虛線流動 Dash offset           | 虛線沿路徑流動                       | 「路線圖上的虛線往前流」               |
| 描邊粗細動畫                   | 線寬隨時間變化                       | 「線條由 1 px 變粗到 12 px」           |
| 形狀變形 Shape morph           | 一個形變成另一個形                   | 「圓變方再變星形」                     |
| 布林運算 Boolean               | 形狀相加、相減、交集                 | 「兩個圓交集處挖空」                   |
| 重複器 Repeater ／ 陣列 Array  | 複製成排、成圈                       | 「12 個方塊放射狀排一圈並依序旋轉」    |
| 偏移路徑 Offset path           | 向內或向外長出輪廓                   | 「外框向外擴 3 層同心輪廓」            |
| 擾動路徑 Wiggle paths          | 輪廓邊緣抖動                         | 「邊緣像手繪般微抖」                   |
| 扭轉 Twist ／ 鋸齒 Zig-zag     | 扭曲輪廓                             | 「線條變成鋸齒狀波浪」                 |
| 融合 Metaball ／ Gooey         | 靠近時像水滴般相連                   | 「兩個圓靠近時黏在一起」               |
| 遮罩揭示 Mask reveal           | 用遮罩慢慢露出內容                   | 「圓形遮罩從中心擴大揭示畫面」         |
| 軌道遮罩 Track matte           | 用一層的形狀或亮度決定另一層哪裡可見 | 「影片只在文字形狀內播放」             |
| 碎裂 Shatter                   | 形狀碎成小片                         | 「logo 碎成三角形散開」                |
| 折疊 Fold                      | 像紙一樣摺起或展開                   | 「卡片像紙一樣對摺收起」               |
| 液態填色 Liquid fill           | 顏色像液體灌滿形狀                   | 「圖示從下往上被液體填滿，表面有波紋」 |
| 圖示動畫 Icon animation        | 圖示狀態間的小動畫                   | 「漢堡選單變成叉叉」                   |

## 字體動態

動態字體（kinetic typography）的單位可以是整句、單詞、單字或筆畫；先說清楚以什麼為單位在動。

| 術語                           | 意思                                                    | 描述範例                               |
|--------------------------------|---------------------------------------------------------|----------------------------------------|
| 逐字 ／ 逐詞 ／ 逐行出現       | 以字、詞、行為單位依序進場                              | 「逐字往上淡入，每字延遲 0.03 秒」     |
| 打字機 Typewriter              | 一個字一個字打出，常帶游標                              | 「打字機效果，結尾游標閃 3 下」        |
| 解碼 Scramble ／ Decode        | 亂碼跳動後定成正確文字                                  | 「標題先是亂碼，0.6 秒內逐字解碼」     |
| 字距動畫 Tracking              | 字母間距拉開或收緊                                      | 「字距從 40 收到 0」                   |
| 可變字體軸 Variable axes       | 字重 wght、字寬 wdth、斜度 slnt、光學尺寸 opsz 連續變化 | 「字重隨音量在 300–900 之間跳動」      |
| 文字跟隨路徑 Text on path      | 文字沿曲線排列與移動                                    | 「文字繞著圓圈轉」                     |
| 文字遮罩 Text mask ／ Knockout | 文字當窗口，透出影像                                    | 「影片只在大字裡面播放」               |
| 漸層流動 Gradient sweep        | 字面上的顏色或光澤流過                                  | 「金屬光澤由左掃到右」                 |
| 逐字彈跳 Stagger bounce        | 每個字依序彈起                                          | 「每個字依序 Q 彈跳起」                |
| 字母重組 Rearrange             | 字母移位組成新字                                        | 「LISTEN 的字母重組成 SILENT」         |
| 字形變形 Glyph morph           | 一個字形變成另一個                                      | 「A 的筆畫變形成 B」                   |
| 動態排版 Kinetic layout        | 字句輪流佔滿畫面、跟著口白節奏                          | 「每個關鍵詞放大佔滿畫面，跟著旁白跳」 |
| 跑馬燈 Marquee                 | 文字無限水平捲動                                        | 「底部一條跑馬燈循環」                 |
| 3D 擠出字 Extruded type        | 文字有厚度可旋轉                                        | 「字厚 40 px，沿 Y 軸轉半圈」          |
| 筆畫描繪 Handwriting           | 依筆順寫出                                              | 「簽名依筆順寫出」                     |
| 文字粒子化 Disintegrate        | 文字散成粒子或碎片                                      | 「字從右邊開始化成沙飄走」             |
| 數字滾動 Counter ／ Odometer   | 數字遞增或像里程表滾動                                  | 「0 滾到 2,346，ease-out」             |
| 下方字卡 Lower third           | 畫面下方的姓名或標題條                                  | 「左下角字卡由左滑入」                 |
| 螢光標記 Highlight             | 字下方畫出底色                                          | 「關鍵字下方刷出黃色螢光」             |
| 穿越文字 Zoom through          | 鏡頭穿過字母的洞                                        | 「推進穿過 O 的中空處」                |

## 3D：材質、光影、光學

3D 的描述分三件事：東西是什麼做的、光從哪裡來、透過什麼樣的鏡頭看。

### 材質

| 術語                                     | 意思                               | 描述範例                     |
|------------------------------------------|------------------------------------|------------------------------|
| PBR 材質                                 | 用底色、粗糙度、金屬度描述表面     | 「粗糙度 0.3 的霧面金屬」    |
| 次表面散射 SSS                           | 光穿進表面再散出，像蠟、皮膚、黏土 | 「邊緣透出暖色，像蠟燭」     |
| 黏土 Clay                                | 霧面、帶指紋與手捏痕跡             | 「黏土質感，表面有細指紋」   |
| 玻璃 Glass                               | 透明、折射、反射                   | 「透明玻璃，邊緣有高光」     |
| 清漆 Clearcoat                           | 表面多一層亮光漆                   | 「車漆般的清漆反光」         |
| 絨面 Sheen                               | 布料邊緣柔和的亮                   | 「絨布質感」                 |
| 自發光 Emission                          | 物體自己發光                       | 「霓虹管自發光」             |
| 虹彩 Iridescence ／ 薄膜干涉             | 角度不同顏色不同，像肥皂泡         | 「肥皂泡般的薄膜虹彩」       |
| 程序紋理 Procedural texture              | 用公式生成的紋理                   | 「表面是程序生成的大理石紋」 |
| 置換 Displacement ／ 法線貼圖 Normal map | 讓表面真的凸起，或只做出凹凸光影   | 「表面隨音樂鼓起波紋」       |
| 卡通著色 Toon shading                    | 色塊分明、帶描邊                   | 「兩階卡通著色加黑色描邊」   |

## 粒子、場與模擬外觀

描述粒子要交代四件事：從哪裡發射、受什麼力、活多久、長什麼樣。

| 術語                       | 意思                           | 描述範例                         |
|----------------------------|--------------------------------|----------------------------------|
| 發射器 Emitter             | 粒子從點、線、面或文字形狀射出 | 「從 logo 輪廓發射」             |
| 發射率 Birth rate          | 每秒產生多少顆                 | 「每秒 5,000 顆」                |
| 生命週期 Lifespan          | 每顆活多久，期間變小變淡       | 「每顆活 2 秒，最後 0.5 秒淡出」 |
| 初速度 ／ 擴散角 Spread    | 射出的速度與角度範圍           | 「向上 30° 錐形噴出」            |
| 重力 ／ 風 ／ 阻力 Drag    | 作用在粒子上的力               | 「受微風往右飄、阻力大」         |
| 吸引子 Attractor ／ 排斥子 | 把粒子吸過去或推開             | 「游標是吸引子」                 |
| 漩渦 Vortex                | 繞軸旋轉的力                   | 「粒子被捲進中心漩渦」           |
| 流場 Flow field            | 每個位置有一個方向，粒子順著流 | 「沿雜訊流場畫出髮絲般的線」     |
| 拖尾 Trails                | 粒子留下軌跡                   | 「每顆拖 0.3 秒的光尾」          |
| 聚合成形 Assemble          | 散亂粒子聚成文字或圖形         | 「星塵在 2 秒內聚成 logo」       |
| 爆散 Explode ／ Disperse   | 形狀炸開成粒子                 | 「logo 在落拍時炸成星塵」        |
| 化為灰燼 Disintegrate      | 由一側開始碎成粉末飄走         | 「人像從右邊化成灰飄散」         |
| 火花 Sparks ／ 煙 ／ 火    | 常見的自然現象粒子             | 「撞擊點噴出火花」               |
| 點雲 Point cloud           | 用大量點描出 3D 形體           | 「人臉由 20 萬個點組成」         |
| 山脊線 Ridge lines         | 一排排起伏線條互相遮擋         | 「58 條山脊線像聲波地形」        |
| 向量場 Vector field        | 用箭頭或短線顯示每點的方向     | 「背景是隨時間轉動的短線場」     |
| 群集 Flocking              | 粒子像鳥群一樣成群行動         | 「點群像椋鳥群翻轉」             |
| 加法混合 Additive blending | 重疊處越疊越亮                 | 「粒子用加法混合，密處發亮」     |
