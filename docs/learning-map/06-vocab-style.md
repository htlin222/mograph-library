# 語彙五：風格

這頁收「一整組選擇的名字」：說出一個風格名，等於一次交代了配色、形狀、運動和質感，對應地圖的六（脈絡）。

## 設計流派與美學

一個流派名稱就是一包預設：配色、字體、形狀、運動方式一起被決定。

| 流派                                   | 視覺特徵                       | 典型動態                 |
|----------------------------------------|--------------------------------|--------------------------|
| 瑞士國際主義 Swiss Style               | 網格、無襯線字、非對稱、高對比 | 沿網格精準滑動、俐落停格 |
| 包浩斯 Bauhaus                         | 圓方三角、紅黃藍黑             | 幾何塊旋轉、對拍換色     |
| 構成主義 Constructivism                | 斜向構圖、紅黑、粗字           | 斜線切入、強力推擠       |
| 裝飾藝術 Art Deco                      | 金色、對稱、放射線             | 放射線展開、對稱開合     |
| 普普藝術 Pop Art                       | 網點、粗黑線、鮮豔色           | 半色調、跳色、漫畫框     |
| 孟菲斯 Memphis                         | 撞色、波浪紋、幾何拼貼         | 俏皮彈跳、隨機散落       |
| 極簡 Minimalism                        | 少元素、大留白                 | 慢而準、細微位移         |
| 扁平設計 Flat                          | 純色塊、無陰影                 | 形狀變形、路徑描繪       |
| 野獸派 Brutalism                       | 粗糙格線、系統字、刻意不精緻   | 硬切、無緩動、突然出現   |
| 新擬態 Neumorphism                     | 同色背景上的柔和凹凸           | 按下時陰影反轉成凹陷     |
| 玻璃擬態 Glassmorphism ／ Liquid Glass | 毛玻璃、半透明、亮邊、折射     | 液態融合、折射變形       |
| 蒸汽波 Vaporwave                       | 粉紫青、雕像、格線地平線       | VHS 故障、慢速漂浮       |
| 合成器浪潮 Synthwave ／ Outrun         | 霓虹日落、線框網格             | 網格向鏡頭無限捲動       |
| 賽博龐克 Cyberpunk                     | 霓虹、雨夜、故障字             | 故障閃爍、掃描線         |
| Y2K                                    | 鉻銀、泡泡、透明塑膠           | 鉻面反光旋轉             |
| 酸性設計 Acid graphics                 | 液態鉻、扭曲字、螢光           | 字體液化扭曲             |
| 復古未來 Retro-futurism                | 50–70 年代想像的未來           | 慢速旋轉、光暈           |

## 媒材與質感風格

媒材風格說的是「看起來像用什麼做的」，和流派可以自由組合，例如「包浩斯 × 剪紙」。

| 風格                               | 特徵                         | 描述範例                       |
|------------------------------------|------------------------------|--------------------------------|
| 黏土動畫 Claymation                | 黏土質感、指紋、微抖         | 「黏土質感，每 2 格微微抖動」  |
| 定格動畫 Stop motion               | 實物逐格拍攝的頓挫           | 「on twos，像定格動畫」        |
| 剪紙 Paper cut-out                 | 紙片層疊、投影、紙邊纖維     | 「多層剪紙，層間有柔和投影」   |
| 逐格手繪 Frame-by-frame            | 每格重畫，線條會「沸騰」     | 「線條每格微變，有手繪呼吸感」 |
| 轉描 Rotoscope                     | 描實拍影片的動作             | 「把舞者轉描成單色線條」       |
| 拼貼 Collage                       | 照片、紙張、字混貼           | 「雜誌剪貼風，元素一跳一跳換」 |
| 水彩 ／ 粉彩 ／ 蠟筆               | 手作畫材的顆粒與暈染         | 「水彩暈染邊緣、紙紋明顯」     |
| 線條藝術 Line art ／ 單線 Monoline | 只用等粗的線                 | 「單線插畫，一筆畫出整個場景」 |
| 2D 扁平向量                        | 乾淨色塊與簡單造型           | 「扁平向量角色，手腳像橡皮管」 |
| 等角插畫 Isometric                 | 30° 等角、沒有透視           | 「等角視角的小城市逐棟長出」   |
| 像素藝術 Pixel art                 | 低解析度、限色盤             | 「16 色像素風，on twos」       |
| 低多邊形 Low poly                  | 少面數、平面著色             | 「低多邊形山脈，每面一色」     |
| 線框 Wireframe                     | 只畫 3D 的邊                 | 「線框地形向前捲動」           |
| 寫實 3D Photoreal                  | 真實材質與光                 | 「商品攝影般的寫實 3D」        |
| 卡通 3D Stylized 3D                | 圓潤造型、柔和光             | 「軟萌卡通 3D，大眼小身」      |
| 霓虹 Neon                          | 發光管線、暗背景             | 「霓虹管逐段點亮」             |
| 全息 ／ 鐳射 Holographic           | 角度變色的金屬虹彩           | 「全息箔片般的虹彩」           |
| 點陣 ／ LED Dot matrix             | 圓點組成的顯示               | 「LED 看板逐點亮起」           |
| 1-bit ／ 遞色                      | 只有黑白兩色，靠網點表現灰階 | 「1-bit 遞色，像老 Mac」       |
| 生成藝術 Generative                | 規則與隨機長出的圖形         | 「流場生成的髮絲線條」         |

## 類型與用途

先說用途，對方就知道長度、節奏和慣例；同一個效果在片頭和 UI 裡的做法完全不同。

| 類型                                       | 慣例                               | 描述範例                            |
|--------------------------------------------|------------------------------------|-------------------------------------|
| 片頭 Title sequence                        | 1–3 分鐘，建立氣氛，名單穿插       | 「Saul Bass 式剪紙片頭」            |
| 片尾名單 End credits                       | 長、慢、可讀                       | 「名單捲動，旁邊放幕後小動畫」      |
| 頻道識別 Ident ／ 包裝 Package             | 3–10 秒，可重複播放                | 「同一個 logo 做 5 種季節版 ident」 |
| 品牌動態 Logo animation ／ Motion identity | 2–5 秒 logo 演出，加上一套動態規範 | 「logo 3 秒演出，加一份動態規範」   |
| 產品發表 Product reveal                    | 慢、精緻、材質特寫                 | 「黑底、輪廓光、慢速環繞產品」      |
| 解說動畫 Explainer                         | 60–90 秒，圖示加旁白               | 「扁平向量解說，跟著旁白逐句出圖」  |
| 資料動畫 Data animation                    | 數字與圖表的轉換                   | 「長條圖由 2020 長到 2025」         |
| UI 微互動 Micro-interaction                | 0.1–0.5 秒的回饋                   | 「按讚時愛心擠壓後彈出小粒子」      |
| 頁面轉換 Page transition                   | 0.3–0.6 秒，交代空間關係           | 「點縮圖放大成詳情頁」              |
| 載入動畫 Loader                            | 無縫循環、不搶戲                   | 「3 個點依序脈衝」                  |
| 新手引導 Onboarding                        | 3–5 頁，一頁一個重點               | 「每頁一個角色動作帶出功能」        |
| 社群短片 Social short                      | 9:16、前 1 秒定勝負                | 「15 秒 Reels，開頭就是爆點」       |
| 短廣告 Bumper                              | 6 秒、一個訊息                     | 「6 秒，只講一句話」                |
| 歌詞影片 Lyric video                       | 文字跟著歌詞節奏                   | 「每句歌詞一種字體動態」            |
| 音樂視覺 Visualizer ／ VJ                  | 跟著音樂即時反應                   | 「低頻驅動的粒子球，現場投影」      |
| 投影映射 Projection mapping                | 投在建築或物體表面                 | 「建築立面像積木般拆解重組」        |
| 遊戲特效 VFX ／ UI                         | 即時、短、強回饋                   | 「升級時金色光柱加粒子」            |

## 參照名單：說「像某某」時可以點名的人與作品

點名一個參照，比十個形容詞更快對齊想像；再補一句「取它的哪一點」，避免整個照抄。

| 人或作品                                          | 代表的效果                   | 描述範例                                 |
|---------------------------------------------------|------------------------------|------------------------------------------|
| Saul Bass《迷魂記》《桃色血案》片頭（1958、1959） | 剪紙幾何、極簡色塊、螺旋     | 「取 Saul Bass 的剪紙色塊，不要人物」    |
| 《迷魂記》的推軌變焦（希區考克，1958）            | 背景伸縮的暈眩感             | 「做一個迷魂記式推軌變焦」               |
| Pablo Ferro《奇愛博士》片頭（1964）               | 手寫字疊在實拍上             | 「手寫細字疊在畫面上」                   |
| Kyle Cooper《火線追緝令》片頭（1995）             | 手刮字、閃爍、神經質剪接     | 「Se7en 片頭那種刮痕與抖動」             |
| Oskar Fischinger《An Optical Poem》（1938）       | 形狀隨古典樂起舞             | 「圓形跟著弦樂一起呼吸」                 |
| Norman McLaren、Len Lye                           | 直接在膠片上畫與刮           | 「手刮膠片般的線條跳動」                 |
| John Whitney《Catalog》（1961）                   | 數學圖形、諧波運動           | 「Whitney 式的諧波點陣」                 |
| 池田亮司 Ryoji Ikeda                              | 黑白數據、極簡電子、高速閃爍 | 「黑底白色數據條紋高速掃描」             |
| Zach Lieberman                                    | 即時程式的詩意手繪感         | 「像 Zach Lieberman 那樣的彩色線條實驗」 |
| Tyler Hobbs《Fidenza》（2021）                    | 流場生成的粗細曲線           | 「Fidenza 式流場曲線」                   |
| Inigo Quilez 的 Shadertoy 作品                    | SDF 光線步進、程序造景       | 「純 SDF 算出來的雕塑」                  |
| Joy Division《Unknown Pleasures》封面（1979）     | 一排排脈衝山脊線             | 「Unknown Pleasures 式的山脊線」         |
| 《蜘蛛人：新宇宙》（2018）                        | 半色調、on twos、套色錯位    | 「新宇宙式的網點與錯位色版」             |
| Wes Anderson 的電影                               | 完全對稱、粉彩、平移鏡頭     | 「Wes Anderson 式對稱構圖」              |
| Apple Liquid Glass（2025）                        | 液態玻璃介面、折射與高光     | 「Liquid Glass 般的通透按鈕」            |
