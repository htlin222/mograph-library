# 語彙四：製作

這頁管「怎麼做成可播放的檔案」，對應地圖的五（製作管線）。跟人或 AI 交代規格時用得到。

## 規格

規格決定作品在哪裡播得對；開工前先講好，避免最後重算。

| 術語                         | 意思                                                       | 描述範例                         |
|------------------------------|------------------------------------------------------------|----------------------------------|
| 解析度 Resolution            | 畫面像素尺寸                                               | 「1080×1920」「4K 3840×2160」    |
| 長寬比 Aspect ratio          | 9:16 直式、16:9 橫式、1:1、4:5                             | 「主版 9:16，另出 1:1」          |
| 影格率 Frame rate            | 24 電影、25 歐洲電視、30 網路影音、60 介面與遊戲           | 「30 fps」                       |
| 時長與格數                   | 秒數 × 影格率 = 總格數                                     | 「6 秒 = 180 格」                |
| 色彩空間 Color space         | sRGB 網頁、Rec.709 影片、Display P3 蘋果螢幕、Rec.2020 HDR | 「Rec.709 交付」                 |
| 位元深度 Bit depth           | 每個顏色通道的階數；8-bit 漸層易斷層                       | 「中間檔用 16-bit 避免漸層斷層」 |
| HDR ／ SDR                   | 高動態範圍或一般範圍                                       | 「只做 SDR」                     |
| 線性工作流程 Linear workflow | 在線性色彩下合成與打光，最後才轉換                         | 「合成用線性，輸出轉 sRGB」      |
| 逐行 Progressive             | 每格是完整畫面（網路影片都是）                             | 「逐行掃描」                     |
| 安全區 Safe area             | 平台介面不會蓋住的範圍                                     | 「直式上下各留 15% 給介面」      |

## 格式與交付

交付分三種去處：給剪接或後製的母帶、給觀眾看的發佈檔、給網頁或 App 的即時動畫。

| 術語                           | 意思                                                                           | 描述範例                           |
|--------------------------------|--------------------------------------------------------------------------------|------------------------------------|
| 母帶 Master ／ ProRes          | 高畫質、檔案大，給後續製作                                                     | 「交 ProRes 422 HQ 母帶」          |
| 發佈檔 H.264 ／ H.265 ／ AV1   | 壓縮給平台播放                                                                 | 「再出一支 H.264 給社群」          |
| 位元率 Bitrate ／ 品質係數 CRF | 壓縮程度，越低越糊                                                             | 「H.264 CRF 18」                   |
| 透明通道 Alpha                 | 背景透明，可疊在別的畫面上                                                     | 「交 ProRes 4444 帶透明」          |
| 影像序列 Image sequence        | 一格一張 PNG 或 EXR                                                            | 「給合成用 EXR 序列」              |
| GIF ／ APNG ／ WebM            | 網頁上的小循環動畫                                                             | 「3 秒無縫循環 WebM」              |
| Lottie                         | 向量動畫的 JSON 檔，通常由 After Effects 匯出；程式路線改用 SVG、CSS 或 Canvas | 「圖示動畫輸出 Lottie」            |
| Rive                           | 可互動、有狀態機的向量動畫，需在 Rive 編輯器製作；程式路線改寫自己的狀態機     | 「按鈕做成 Rive 狀態機」           |
| CSS ／ SVG 動畫                | 直接寫在網頁裡的動畫                                                           | 「載入動畫用純 CSS」               |
| 音訊規格                       | 影片常用 48 kHz；母帶 WAV，發佈 AAC                                            | 「音訊 48 kHz、AAC 256k」          |
| 字幕檔 SRT                     | 外掛字幕                                                                       | 「附 SRT 中英字幕」                |
| 封面格 Poster frame            | 影片未播放時顯示的那一格                                                       | 「封面用第 3 秒那格」              |
| 交付清單 Deliverables          | 所有要交的版本與規格                                                           | 「9:16、1:1、16:9 各一，加無字版」 |

## 程式動態的常用動詞

用程式做動態時天天用到的操作；聽懂它們，就能和工程師或 AI 對上話。

| 術語                             | 意思                                               | 描述範例                                     |
|----------------------------------|----------------------------------------------------|----------------------------------------------|
| 渲染迴圈 Render loop             | 每格呼叫一次繪製，瀏覽器裡用 requestAnimationFrame | 「用 rAF 迴圈，暫停時停止繪製」              |
| 時間函數 frame(t)                | 每格畫面只由時間 t 決定                            | 「每段寫成 frame(t)，可以直接跳到第 3.2 秒」 |
| 無狀態 ／ 有狀態                 | 能直接算出任一格，或必須從頭逐步推進               | 「粒子用無狀態公式，物理用有狀態模擬」       |
| 確定性 ／ 隨機種子               | 同樣輸入永遠得到同樣畫面                           | 「不用 Math.random，改用固定種子的亂數」     |
| 固定步長 Fixed timestep          | 模擬每次前進固定時間，與顯示格率無關               | 「物理用 240 Hz 固定步長」                   |
| 參數化 Parameterize              | 把數字集中成變數或設定檔                           | 「顏色、時長全部集中在一個設定物件」         |
| 參數面板                         | 用滑桿即時調數值，不改程式碼                       | 「接一個 lil-gui 面板調彈簧剛性」            |
| 熱重載 Hot reload                | 存檔後畫面立即更新                                 | 「改著色器時保持熱重載」                     |
| 離屏緩衝 Offscreen buffer ／ FBO | 先畫在看不見的畫布或貼圖上，再合成                 | 「先把 3D 畫進緩衝，再做後製」               |
| 乒乓緩衝 Ping-pong               | 兩張緩衝輪流讀寫，用於 GPU 模擬                    | 「反應擴散用乒乓緩衝」                       |
| 後製 pass                        | 對整個畫面再跑一次著色器                           | 「最後加一道顆粒 pass」                      |
| 圖層合成 Layering                | 多張畫布用混合模式疊起來                           | 「2D 字卡疊在 WebGL 畫布上」                 |
| 逐格擷取 Frame capture           | 把每一格存成圖片                                   | 「每格輸出 PNG」                             |
| 無頭算圖 Headless render         | 不開視窗、在伺服器上用瀏覽器出片                   | 「用 Playwright 無頭算圖」                   |
| 編碼 Encode                      | 把影格序列壓成影片                                 | 「用 ffmpeg 編成 H.264」                     |
| 縮圖檢查 Contact sheet           | 把多個時間點並排成一張圖檢查                       | 「每段出 5 張縮圖並排」                      |
| 場景契約 Scene contract          | 每段遵守同一套介面，方便分工與組裝                 | 「每段都提供 init 和 frame(t)」              |
| 效能分析 Profiling               | 量每格花幾毫秒                                     | 「這段每格 1.2 秒，要降到 0.5」              |
| 自適應畫質 Adaptive quality      | 掉格時自動降低解析度                               | 「低於 30 fps 就把 GL 解析度降到 0.7」       |
| 版本控制 git                     | 記錄每次修改，可回到任一版                         | 「每次交件打一個 tag」                       |

GUI 軟體的動詞在程式裡都有對應：預合成約等於把一段繪製包成函式；空物件約等於群組變換；調整圖層約等於後製 pass；表達式就是程式本身；烘焙約等於先算好存成資料。
