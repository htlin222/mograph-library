# 語彙三：構成

這頁管「多個動作、鏡頭、畫面與聲音之間怎麼組織」，對應地圖的四（構成與視聽）。

## 畫面構成

構成管「某一瞬間畫面怎麼排」；動態作品的每一個停格，都應該是一張好看的海報。

| 術語                                     | 意思                             | 描述範例                             |
|------------------------------------------|----------------------------------|--------------------------------------|
| 三分法 Rule of thirds                    | 主體放在三等分線的交點           | 「主體在右上三分點」                 |
| 置中構圖 ／ 對稱                         | 主體正中、左右對稱               | 「完全對稱，像 Wes Anderson」        |
| 負空間 ／ 留白 Negative space            | 刻意空出大面積                   | 「畫面 70% 留白，字很小」            |
| 視覺層級 Hierarchy                       | 大小、對比決定先看什麼           | 「標題最大，數字次之，說明最小」     |
| 焦點 Focal point                         | 視線停留的唯一位置               | 「全畫面只有一個彩色點」             |
| 前中後景 Foreground ／ Mid ／ Background | 分層產生深度                     | 「前景樹葉模糊、中景人物、後景城市」 |
| 景別 Shot size                           | 大遠景、全景、中景、特寫、大特寫 | 「從大遠景一路推到眼睛特寫」         |
| 引導線 Leading lines                     | 線條帶視線走向主體               | 「道路透視線引向 logo」              |
| 框中框 Frame within frame                | 用門窗或形狀再框一次             | 「從手機螢幕裡看到主畫面」           |
| 網格系統 Grid                            | 用欄位網格對齊所有元素           | 「12 欄網格，邊界 84 px」            |
| 安全區 Safe area                         | 不會被介面或裁切擋住的範圍       | 「字放在上下各留 15% 的安全區內」    |
| 長寬比 Aspect ratio                      | 9:16 直式、16:9 橫式、1:1、4:5   | 「9:16 直式，給 Reels 用」           |
| 視覺重量 ／ 平衡 Balance                 | 左右上下的輕重分配               | 「左邊大色塊，右邊用小字平衡」       |
| 出血 Full bleed                          | 畫面延伸到邊緣以外               | 「背景圖滿版出血」                   |
| 比例對比 Scale contrast                  | 極大與極小並置                   | 「巨大的字旁邊放一行小註解」         |

## 色彩

色彩在動態裡多了一個維度：它會隨時間改變。描述時說清楚色盤、對比，以及顏色在哪一刻怎麼變。

| 術語                           | 意思                             | 描述範例                                    |
|--------------------------------|----------------------------------|---------------------------------------------|
| 色盤 Palette                   | 整支片使用的有限顏色組           | 「全片只用 4 色：墨黑、米白、珊瑚紅、鈷藍」 |
| 主色、輔色、強調色             | 常見比例約 60:30:10              | 「強調色只給要觀眾看的那個元素」            |
| 色相 ／ 彩度 ／ 明度           | 顏色的三個軸                     | 「色相不變，只把彩度降到 30%」              |
| 明度對比 Value contrast        | 亮暗差異，決定能不能一眼看清     | 「字和背景明度差要大」                      |
| 互補色 ／ 類比色 ／ 三角配色   | 色相環上的經典組合               | 「藍橘互補，製造張力」                      |
| 單色 Monochrome                | 只用一個色相的深淺               | 「整段只用不同深淺的藍」                    |
| 冷暖 Warm ／ Cool              | 冷色後退、暖色前進               | 「前景暖、背景冷，拉出深度」                |
| 漸層 ／ 網格漸層 Mesh gradient | 平滑過渡的顏色                   | 「背景是緩慢流動的網格漸層」                |
| 程序配色 Procedural palette    | 用公式生成和諧色盤               | 「用餘弦配色公式每段換一組色」              |
| 感知均勻色彩 OKLab ／ OKLCH    | 數值變化和眼睛感覺一致的色彩空間 | 「漸層在 OKLab 內插，中間不會變灰」         |
| 色彩腳本 Color script          | 整支片每段主色的排列             | 「從冷藍一路走到暖橘，結尾回到黑」          |
| 色彩節奏                       | 顏色依節拍或情緒切換             | 「每拍換一次背景色」                        |
| 深色 ／ 淺色模式               | 同一設計的兩套色                 | 「深淺兩套配色都要成立」                    |
| 對比度 Contrast ratio          | 文字可讀性的量化標準（WCAG）     | 「文字對比至少 4.5:1」                      |
| 色盲友善                       | 不只靠顏色區分資訊               | 「紅綠之外再加形狀差異」                    |

## 編排與交錯

編排（choreography）管多個元素「誰先誰後、怎麼接力」；同樣的動作，編排不同就是不同作品。

| 術語                                        | 意思                               | 描述範例                                   |
|---------------------------------------------|------------------------------------|--------------------------------------------|
| 進場 Entrance ／ 出場 Exit ／ 強調 Emphasis | 動態的三種目的                     | 「進場用滑入，強調用脈衝，出場用淡出」     |
| 交錯 Stagger                                | 同一動作依序延遲啟動               | 「6 張卡片依序進場，每張延遲 0.05 秒」     |
| 交錯方向                                    | 由左到右、由中心向外、隨機、依距離 | 「從中心向外擴散地交錯」                   |
| 連鎖 Cascade                                | 一排元素像瀑布般依序落下           | 「清單項目由上而下連鎖落入」               |
| 波紋 Ripple                                 | 從一點向外一圈圈影響               | 「點擊處向外泛起波紋，周圍格子依序跳起」   |
| 循序 Sequential ／ 同時 Simultaneous        | 一個做完再下一個，或一起動         | 「標題和圖片同時進場，按鈕最後」           |
| 接力 Hand-off                               | 前一個動作結束觸發下一個           | 「球滾到字邊把字撞亮」                     |
| 主從動作 Motion hierarchy                   | 主動作最大最先，次要動作較小較晚   | 「主圖大位移，周邊小圖示只微動」           |
| 跟隨 Follow the leader                      | 一個帶頭，其他跟在後面             | 「游標拖著一串圓點跟隨」                   |
| 共享元素轉換 Shared element                 | 同一個元素從 A 畫面變形到 B 畫面   | 「縮圖放大成全螢幕詳情頁」                 |
| 循序揭露 Progressive disclosure             | 資訊一層層出現                     | 「先出數字，再出單位，最後出註解」         |
| 對位 Counterpoint                           | 兩組元素反向或錯位運動             | 「上排往左、下排往右」                     |
| 鏡像編排 Mirror                             | 左右或上下對稱地同步運動           | 「左右兩半鏡像展開」                       |
| 視線引導 Eye trace                          | 用運動把觀眾視線帶到下一個位置     | 「每段結尾的動作停在下一段主體出現的位置」 |
| 群組 Grouping                               | 相關元素一起進出                   | 「圖示和它的標籤當作一組進場」             |

## 鏡頭運動

鏡頭詞彙來自電影攝影；虛擬攝影機做得到真實攝影機做不到的事，例如穿過物體、無限縮放。

| 術語                               | 意思                               | 描述範例                                   |
|------------------------------------|------------------------------------|--------------------------------------------|
| 推軌 Dolly in ／ out               | 攝影機實際前進或後退               | 「緩慢推近 logo，3 秒推進 20%」            |
| 變焦 Zoom                          | 改焦距放大，攝影機不動             | 「快速變焦拉近，帶點戲劇感」               |
| 搖 Pan ／ 俯仰 Tilt                | 攝影機原地左右轉、上下轉           | 「由下往上俯仰，露出整棟建築」             |
| 橫移 Truck ／ 升降 Pedestal、Crane | 攝影機平移或升降                   | 「橫移經過一排產品」                       |
| 環繞 Orbit ／ Arc shot             | 繞著主體轉                         | 「繞產品轉半圈」                           |
| 跟拍 Tracking shot                 | 跟著移動的主體走                   | 「跟著飛行的紙飛機一路前進」               |
| 手持 Handheld ／ 鏡頭震動 Shake    | 微晃的真實感，或撞擊時的震動       | 「輕微手持晃動」                           |
| 推軌變焦 Dolly zoom                | 一邊推一邊反向變焦，背景伸縮       | 「主體大小不變，背景向後拉伸」             |
| 飛越 Fly-through                   | 鏡頭在空間中穿梭前進               | 「鏡頭飛進無限重複的晶格」                 |
| 穿越物件 Through-object            | 鏡頭穿過孔洞或物體進入下一個空間   | 「推進穿過 O 的中空處」                    |
| 無限縮放 Infinite zoom ／ Droste   | 不斷放大，畫中畫無盡重複           | 「一路放大進畫中畫，循環 3 層」            |
| 轉焦 Rack focus                    | 焦點從一個物體移到另一個           | 「焦點從前景的杯子轉到背景的人」           |
| 2.5D 視差 ／ 相機投影              | 平面圖層分前後，鏡頭一動產生立體感 | 「老照片做 2.5D 視差推進」                 |
| 俯視 Top-down ／ 低角度 Low angle  | 從正上方看，或從下往上看           | 「正上方俯視的桌面」「低角度仰拍顯得巨大」 |
| 荷蘭角 Dutch angle                 | 畫面傾斜                           | 「傾斜 15° 增加不安感」                    |
| 一鏡到底 Oner                      | 整段不剪接                         | 「整支片一鏡到底，用鏡頭運動串場」         |

## 轉場

轉場是兩段之間的接縫；好的轉場讓觀眾感覺不到剪接，或刻意讓剪接本身成為看點。

| 術語                             | 意思                                     | 描述範例                             |
|----------------------------------|------------------------------------------|--------------------------------------|
| 硬切 Cut                         | 直接換畫面                               | 「每段在落拍硬切」                   |
| 對拍剪接 Cut on beat             | 剪接點對齊音樂拍點                       | 「所有剪接點對齊大鼓」               |
| 疊化 Dissolve                    | 兩畫面交疊漸變                           | 「1 秒慢疊化」                       |
| 淡入淡出 Fade ／ 黑場、白場 Dip  | 經過全黑或全白                           | 「白閃 2 格再接下一段」              |
| 擦除 Wipe                        | 一條邊界掃過換畫面                       | 「斜線由左上擦到右下」               |
| 遮罩轉場 Mask transition         | 用形狀擴大露出下一段                     | 「圓形從中心擴大露出下一段」         |
| 圖形匹配 Graphic match cut       | 兩段形狀相似處接在一起                   | 「圓形月亮接到圓形咖啡杯口」         |
| 動作匹配 Match on action         | 上一段的動作在下一段延續                 | 「上一段丟出的球，下一段被接住」     |
| 顏色匹配 Color match             | 以同一個顏色銜接                         | 「整畫面變紅，下一段從紅色背景開始」 |
| 推擠 Push ／ 滑動 Slide          | 新畫面把舊畫面推出去                     | 「新畫面從右推入」                   |
| 縮放轉場 Zoom transition         | 放大進入某個細節到下一段                 | 「放大進入螢幕裡的畫面」             |
| 穿越轉場                         | 鏡頭穿過物體進入下一段                   | 「穿過字母 O，裡面就是下一段」       |
| 鞭搖 Whip pan                    | 快速甩鏡帶動態模糊                       | 「甩鏡到右邊接下一段」               |
| 變形轉場 Morph                   | 上一段的主體變形成下一段的主體           | 「圓點變形成下一段的 logo」          |
| 故障轉場 Glitch transition       | 用故障效果切換                           | 「故障 4 格切到下一段」              |
| 翻轉 Flip ／ 翻頁 Page turn      | 像翻卡片或翻書                           | 「整個畫面像卡片翻到背面」           |
| 分割畫面 Split screen            | 畫面切成多格再合併或替換                 | 「畫面分成 4 格，逐格換成新內容」    |
| 隱形剪接 Hidden cut              | 借遮擋物或黑暗藏住剪接點                 | 「鏡頭掠過柱子時接到下一場」         |
| 聲音先行 J-cut ／ 聲音延後 L-cut | 下一段的聲音提早進來，或上一段的聲音延續 | 「下一段的雨聲提前 1 秒出現」        |

## 敘事結構與節奏

短片也有起承轉合；描述一整支片時，先給段落結構和秒數，再談每段的效果。

| 術語                              | 意思                           | 描述範例                            |
|-----------------------------------|--------------------------------|-------------------------------------|
| 鉤子 Hook                         | 開頭 1–3 秒抓住注意力          | 「第一秒就是最強的畫面」            |
| 建立 Establish                    | 交代場景、主角、規則           | 「前 2 秒先讓觀眾看懂這是一個時鐘」 |
| 鋪陳 Build-up                     | 逐步累積密度與張力             | 「元素越來越多、節奏越來越快」      |
| 揭示 Reveal                       | 把藏著的東西露出來             | 「最後才露出這些線條其實是一個字」  |
| 高潮 Climax ／ 爆點 Drop          | 最強的一刻，常對齊音樂爆點     | 「第 8 秒落拍時全部爆開」           |
| 收尾 Resolve ／ Button            | 結束的那一下                   | 「最後一個小彈跳當句點」            |
| 片尾卡 End card ／ Logo sting     | 品牌收尾的 2–3 秒              | 「結尾 logo sting 2 秒」            |
| 呼吸 Breather ／ 留白             | 刻意的慢或靜                   | 「高潮前留 1 秒空白」               |
| 重複與變奏 Repetition & variation | 同一動作重複，但每次改一點     | 「同樣的彈跳出現 4 次，每次換材質」 |
| 對比 Contrast                     | 快與慢、大與小、滿與空交替     | 「密集快剪之後接一個長鏡頭」        |
| 節奏曲線 Pacing curve             | 整支片能量隨時間的起伏         | 「能量低、中、低、最高、收」        |
| 循環敘事 Loop narrative           | 結尾接回開頭                   | 「最後一格就是第一格」              |
| 分鏡 Storyboard                   | 每個鏡頭一張草圖加秒數         | 「先出 8 格分鏡」                   |
| 風格框 Style frame                | 定稿等級的代表畫面             | 「先做 3 張風格框確認方向」         |
| 動態草稿 Animatic                 | 分鏡配上時間與聲音的粗剪       | 「先做配樂版動態草稿對節奏」        |
| 長度規格                          | 常見 6 秒、15 秒、30 秒、60 秒 | 「15 秒版與 6 秒版各一」            |

## 聲音與同步

聲音決定一半的動態感；描述時說清楚「哪個畫面事件對哪個聲音」。

| 術語                            | 意思                           | 描述範例                              |
|---------------------------------|--------------------------------|---------------------------------------|
| 拍 ／ 小節 ／ BPM               | 音樂的時間格線                 | 「120 BPM，4/4 拍」                   |
| 同步點 Sync point               | 畫面事件與聲音對齊的那一格     | 「球落地那一格對齊大鼓」              |
| 卡通式同步 Mickey-mousing       | 每個動作都配一個聲音           | 「每個字彈出都配一聲 pop」            |
| 聲畫對位 Counterpoint           | 聲音刻意和畫面情緒相反         | 「爆炸畫面配上安靜的鋼琴」            |
| 鋪墊 Riser ／ Build             | 越來越高、越來越大的聲音       | 「爆點前 2 秒 riser」                 |
| 爆點 Drop                       | 鋪墊之後的主段落               | 「drop 時粒子炸開」                   |
| 嗖聲 Whoosh                     | 快速移動的風聲                 | 「甩鏡配 whoosh」                     |
| 衝擊 Impact ／ Hit              | 低頻撞擊聲                     | 「logo 落定配低頻 impact」            |
| 介面音 UI sound                 | 點擊、切換的短音               | 「切換時一聲短促的 tick」             |
| 擬音 Foley                      | 模擬真實物件的聲音             | 「紙張翻動的擬音」                    |
| 氛圍 Ambience ／ 底噪 Room tone | 持續的環境聲                   | 「全片底下鋪一層城市氛圍」            |
| 音樂提示 Sting ／ Stinger       | 短短一句音樂標記               | 「片頭 2 秒品牌 sting」               |
| 側鏈 Sidechain ／ 閃避 Ducking  | 鼓或人聲出現時其他聲音自動壓低 | 「大鼓一下，貝斯就讓開」              |
| 殘響 Reverb ／ 延遲 Delay       | 空間感與回音                   | 「鐘聲帶長殘響」                      |
| 聲像 Panning                    | 聲音在左右的位置               | 「物件從左飛到右，聲音跟著移動」      |
| 靜默 Silence                    | 刻意的無聲                     | 「高潮前 0.5 秒全靜音」               |
| 響度 Loudness（LUFS）           | 感知音量的標準量法             | 「整體 −14 LUFS，峰值不超過 −1 dBTP」 |

## 動態設計系統

動態設計系統把時長、曲線、編排寫成可重複使用的規則；在程式路線裡，它就是一組變數與函式。SCAD 的「品牌動態系統」課和 Material Design、IBM Carbon 的 motion 規範都屬於這一類。

| 術語                        | 意思                                 | 描述範例                                   |
|-----------------------------|--------------------------------------|--------------------------------------------|
| 動態原則 Motion principles  | 品牌或產品對動態的幾條總原則         | 「快速、有依據、不搶戲」                   |
| 時長 token                  | 幾個固定的時長等級                   | 「短 150 ms、中 300 ms、長 600 ms」        |
| 緩動 token                  | 幾條固定的曲線                       | 「標準、強調、進場、離場四條曲線」         |
| 距離與時長                  | 移動越遠，時長越長                   | 「位移超過畫面一半時用長時長」             |
| 進出場模式                  | 固定的進場、出場組合                 | 「進場由下淡入，出場直接淡出」             |
| 編排規則                    | 交錯延遲、順序的固定規則             | 「清單交錯每項 30 ms，最多 8 項」          |
| 招牌動態 Signature motion   | 一看就認得出是這個品牌的動作         | 「所有元素都帶一點回彈，是品牌招牌」       |
| 減少動態 Reduced motion     | 尊重使用者「減少動態效果」的系統設定 | 「開啟減少動態時，改成單純淡入淡出」       |
| 效能預算 Performance budget | 動態不能拖慢畫面                     | 「維持 60 fps，只動 transform 和 opacity」 |
| 規範文件                    | 寫下規則與範例，讓所有人照做         | 「每條 token 附一個可播放的範例」          |
| 程式實作                    | token 存成變數，元件直接引用         | 「時長與曲線寫成 CSS 變數與 JSON」         |
