# 語彙一：運動

這頁管「數值怎麼隨時間變化」，對應地圖的一（運動原理）與二（運動來源）。每個詞附一句可直接拿去用的描述。

## 時間與節奏

時間是動態的第一個變數：先說清楚「何時、多久、落在哪一拍」，其他描述才有意義。

| 術語                                 | 意思                                              | 描述範例                            |
|--------------------------------------|---------------------------------------------------|-------------------------------------|
| 時距 Timing                          | 一個動作花多少時間，決定重量與情緒                | 「縮放花 0.4 秒」                   |
| 間距 Spacing                         | 每格之間位移大小的分布                            | 「前段間距大、到位前越來越密」      |
| 時長 Duration                        | 整段或單一動作的總長                              | 「全片 15 秒，每段 3 秒」           |
| 延遲 Delay ／ 偏移 Offset            | 開始時間往後推                                    | 「副標比主標晚 0.2 秒」             |
| 停格 Hold                            | 到位後停住不動的時間                              | 「到位後停 0.5 秒再離場」           |
| 影格率 fps                           | 每秒幾格；24 有電影感，30 常用於影音，60 用於介面 | 「30 fps」                          |
| 一格一動 on ones ／ 兩格一動 on twos | 每 1 或 2 格才更新畫面，後者有手作頓挫感          | 「角色 on twos，鏡頭 on ones」      |
| 時間量化 Posterize time              | 把動作卡到固定格數更新                            | 「每 3 格跳一次，像定格動畫」       |
| 速度坡度 Speed ramp                  | 同一鏡頭內忽快忽慢                                | 「前半慢動作，撞擊瞬間加速到 4 倍」 |
| 慢動作 ／ 快動作                     | 時間被拉長或壓縮                                  | 「爆炸以 0.25 倍速播放」            |
| 時間重映射 Time remap                | 任意改寫「畫面時間對應真實時間」                  | 「時間先倒退 0.5 秒再往前衝」       |
| 定格 Freeze frame                    | 畫面突然凍結                                      | 「在最高點定格 3 格」               |
| 倒放 Reverse                         | 時間反向                                          | 「碎片倒放回原本的字」              |
| 循環 Loop                            | 動作重複播放                                      | 「3 秒循環」                        |
| 無縫循環 Seamless loop               | 最後一格接回第一格看不出接縫                      | 「做成無縫循環 GIF」                |
| 來回循環 Ping-pong                   | 播完倒著播回來                                    | 「左右擺動用 ping-pong」            |
| 拍 Beat ／ BPM                       | 音樂的時間單位；120 BPM 一拍 0.5 秒               | 「120 BPM，每拍換一次顏色」         |
| 小節 Bar ／ 落拍 Downbeat            | 4 拍一小節，第一拍是落拍                          | 「剪接點都放在落拍」                |
| 反拍 Off-beat ／ 切分 Syncopation    | 動作落在拍與拍之間                                | 「小元素在反拍彈出」                |
| 前導 Lead-in ／ 尾巴 Tail            | 主動作前的鋪墊、後的餘韻                          | 「留 0.3 秒尾巴讓殘影散掉」         |

## 緩動曲線與彈簧

曲線決定「同樣花 0.5 秒，感覺卻完全不同」；說出曲線名稱或彈簧參數，比說「順一點」精確得多。

| 術語                                     | 意思                                              | 描述範例                            |
|------------------------------------------|---------------------------------------------------|-------------------------------------|
| 線性 Linear                              | 等速，機械感                                      | 「跑馬燈用線性等速」                |
| 緩入 Ease-in                             | 慢起快收，像被吸走，適合離場                      | 「離場用 ease-in」                  |
| 緩出 Ease-out                            | 快起慢停，像滑進來，適合進場                      | 「進場用 ease-out」                 |
| 緩入緩出 Ease-in-out                     | 兩頭慢中間快，適合畫面內移動                      | 「卡片換位用 ease-in-out」          |
| 曲線強度                                 | 由緩到陡：sine、quad、cubic、quart、quint、expo   | 「ease-out quint，比 cubic 更急停」 |
| 三次貝茲 Cubic-bezier                    | 四個數字自訂曲線                                  | 「cubic-bezier(0.2, 0, 0, 1)」      |
| 數值圖 Value graph ／ 速度圖 Speed graph | 軟體裡看曲線的兩種方式                            | 「速度圖要是尖峰在前段的山形」      |
| 貝茲把手 Handles ／ 影響 Influence       | 拉長把手，加減速更極端                            | 「出場把手影響拉到 80%」            |
| 步進 Step ／ 停格關鍵影格 Hold keyframe  | 不補間，瞬間跳值                                  | 「顏色用 hold 關鍵影格硬切」        |
| 回彈 Back ／ 過衝 Overshoot              | 衝過目標再退回                                    | 「超過 8% 再回到位」                |
| 彈性 Elastic                             | 到位後來回震盪幾次                                | 「elastic，震 3 次」                |
| 彈跳 Bounce                              | 像落地反彈數次                                    | 「落下用 bounce，彈 2 下」          |
| 彈簧 Spring                              | 用剛性、阻尼、質量三個參數模擬                    | 「spring 剛性 170、阻尼 26」        |
| 剛性 Stiffness                           | 越大越快、越有力                                  | 「剛性調高到 300，更急」            |
| 阻尼比 Damping ratio                     | 小於 1 會晃，等於 1 最快且不晃，大於 1 慢慢靠過去 | 「阻尼比 0.5，晃兩下停」            |
| 恢復係數 Restitution                     | 每次反彈剩多少比例的速度                          | 「恢復係數 0.6」                    |
| 慣性 Inertia ／ 減速 Deceleration        | 用力甩出去後慢慢停                                | 「像 iPhone 捲動那樣甩出後減速」    |
| 平滑跟隨 Smooth follow ／ Lerp           | 每格往目標靠近固定比例                            | 「游標延遲跟隨，每格追 15%」        |

## 動畫原則與動作細節

前 12 個是迪士尼的動畫十二原則（《The Illusion of Life》），後面是讓動作變「活」的常見細節。

| 術語                                | 意思                                   | 描述範例                              |
|-------------------------------------|----------------------------------------|---------------------------------------|
| 擠壓與伸展 Squash & stretch         | 受力時壓扁、高速時拉長，體積不變       | 「落地壓扁 40%，空中沿速度方向拉長」  |
| 預備動作 Anticipation               | 主動作前反方向的小動作                 | 「跳之前先往下蹲 0.2 秒」             |
| 舞台呈現 Staging                    | 讓觀眾一眼看到重點                     | 「其他元素變暗，只有按鈕在動」        |
| 連續動作 ／ 姿勢對姿勢              | 從頭一路畫下去，或先定關鍵姿勢再補中間 | 「火焰用連續動作，角色用姿勢對姿勢」  |
| 跟隨與重疊 Follow-through & overlap | 主體停了，附屬部分晚一點才停           | 「卡片停下後，陰影和標籤晚 2 格才停」 |
| 慢入慢出 Slow in & slow out         | 開始和結束放慢                         | 同緩入緩出                            |
| 弧線 Arcs                           | 自然動作走弧線而非直線                 | 「圖示沿弧線飛進購物車」              |
| 次要動作 Secondary action           | 輔助主動作的小動作                     | 「球落地時地面泛起一圈波紋」          |
| 時間 Timing                         | 格數決定重量與情緒                     | 見〈時間與節奏〉                      |
| 誇張 Exaggeration                   | 放大動作讓意圖更清楚                   | 「錯誤提示左右搖 3 次，幅度誇張」     |
| 立體感 Solid drawing                | 形體有體積、透視正確                   | 「翻牌時看得到卡片厚度」              |
| 吸引力 Appeal                       | 讓角色或物件討喜、好看                 | 「圓潤造型、比例頭大身小」            |
| 拖影 Smear frame                    | 高速時把物體畫成一條拉長的形           | 「揮動那 2 格用拖影」                 |
| 動態模糊 Motion blur                | 依速度產生模糊，快門角度 180° 最常見   | 「開動態模糊，快門 180°」             |
| 殘影 Echo ／ 洋蔥皮 Onion skin      | 留下前幾格的半透明影子                 | 「留 6 個殘影，每 2 格一個」          |
| 運動軌跡 Motion trail               | 走過的路徑留下線                       | 「身後拖一條漸隱的軌跡線」            |
| 收尾晃動 Settle ／ Jiggle           | 到位後的小幅晃動                       | 「到位後晃 2 下停」                   |
| 擺動 Wiggle ／ 抖動 Jitter          | 隨機小幅位移                           | 「每秒 8 次、幅度 3 px 的抖動」       |
| 震動 Shake                          | 衝擊時整體震動                         | 「撞擊時鏡頭震 0.3 秒」               |
| 待機 Idle ／ 呼吸 Breathing         | 靜止時仍有微小週期動作                 | 「待機時每 3 秒縮放 3% 呼吸」         |
| 脈衝 Pulse                          | 一次性的放大再回復，用來強調           | 「通知圖示脈衝一次」                  |
| 拖曳 Drag                           | 柔軟部分落後於主體                     | 「布條跟在旗桿後面甩」                |
| 重心轉移 Weight shift               | 動作中身體重量的移動                   | 「落地時重心下沉再回正」              |

## 感覺形容詞 → 參數

形容詞是你的直覺，參數是別人能照做的指令；說完形容詞，再補一句右欄的做法。數值是起點，不是標準答案。

| 形容詞           | 時距                      | 曲線與物理                      | 其他細節                         |
|------------------|---------------------------|---------------------------------|----------------------------------|
| 俐落 crisp       | 0.2–0.35 秒               | ease-out expo，不回彈           | 一次到位，無多餘動作             |
| 銳利 snappy      | 0.12–0.2 秒               | 極陡 ease-out                   | 配短促點擊聲                     |
| Q 彈 bouncy      | 0.4–0.6 秒                | 彈簧阻尼比 0.4–0.6，過衝 10–20% | 到位後小晃、可加擠壓伸展         |
| 沉重 heavy       | 0.6–1.0 秒                | 慢加速、落地急停，幾乎不回彈    | 長預備、落地鏡頭震動、低頻衝擊聲 |
| 輕盈 floaty      | 1–3 秒                    | sine 緩入緩出                   | 小幅上下漂浮、陰影淡             |
| 黏稠 gooey       | 0.6–1.2 秒                | 低剛性彈簧、延遲跟隨            | 融合球 smooth-min、分離時拉絲    |
| 液態 liquid      | 0.8–1.5 秒                | 連續不停頓                      | 表面波紋、折射、形狀持續流動     |
| 機械 mechanical  | 依節拍                    | 線性或步進                      | 精確停格、等速、齒輪般同步       |
| 有機 organic     | 不固定                    | 雜訊驅動                        | 不對稱時距、元素彼此錯開         |
| 流暢 fluid       | 動作首尾相接              | ease-in-out                     | 60 fps、無停頓、用弧線           |
| 頓挫 choppy      | 依節拍                    | 步進                            | on twos 或 on threes             |
| 爆發 explosive   | 預備 0.2 秒＋爆發 0.15 秒 | 先收縮，再 ease-out expo 放大   | 白閃、粒子、衝擊聲               |
| 緊張 tense       | 短，剪接頻繁              | 急停                            | 微抖動、高頻音、畫面偏暗         |
| 慵懶 dreamy      | 長，2 秒以上              | 很緩的 sine                     | 慢動作、長疊化、柔焦、光暈       |
| 俏皮 playful     | 0.3–0.5 秒                | 回彈                            | 擠壓伸展、不規則交錯             |
| 精緻 premium     | 0.6–0.9 秒                | 慢的 ease-in-out                | 動的元素少、留白多、細微視差     |
| 呼吸感 breathing | 2–4 秒一週期              | 正弦                            | 縮放或亮度變化 2–5%              |
| 隆重 epic        | 長                        | 緩慢推進                        | 低角度、體積光、鼓聲漸強         |

## 基本變換

任何物件都能做的基本動作；描述時寫明「從多少到多少」和「繞哪個點」。

| 術語                                        | 意思                    | 描述範例                                |
|---------------------------------------------|-------------------------|-----------------------------------------|
| 位移 Position                               | 移動位置                | 「從畫面外右側滑到中央」                |
| 旋轉 Rotation                               | 繞錨點轉動              | 「順時針轉 90°」                        |
| 縮放 Scale                                  | 等比或只拉一個方向      | 「從 0% 放大到 100%」「只把高度壓到 0」 |
| 透明度 Opacity                              | 淡入淡出                | 「0.3 秒淡入」                          |
| 錨點 Anchor point ／ 樞軸 Pivot             | 旋轉與縮放的中心        | 「錨點設在左下角，像門一樣打開」        |
| 斜切 Skew                                   | 平行四邊形般傾斜        | 「移動時往行進方向斜切 10°」            |
| 翻轉 Flip                                   | 鏡像翻面                | 「卡片沿 Y 軸翻面顯示背面」             |
| 3D 旋轉                                     | 繞 X、Y、Z 軸，產生透視 | 「沿 X 軸向後倒 60°」                   |
| Z 深度 ／ 透視 Perspective                  | 前後距離與近大遠小      | 「從遠處往鏡頭飛來」                    |
| 路徑動畫 Motion path                        | 沿一條曲線移動          | 「沿 S 形路徑飛入」                     |
| 自動轉向 Auto-orient                        | 物件朝行進方向轉        | 「紙飛機沿路徑自動轉向」                |
| 父子連結 Parenting                          | 子物件跟著父物件動      | 「標籤綁在卡片上一起移動」              |
| 視差 Parallax                               | 前中後景移動速度不同    | 「前景移動 100 px、背景只動 20 px」     |
| 顏色變化 Color shift ／ 色相旋轉 Hue rotate | 顏色隨時間改變          | 「每拍換一次主色」                      |
| 模糊 Blur in ／ out                         | 由糊轉清或反之          | 「從 20 px 模糊對焦到清晰」             |
| 裁切 Clip ／ 遮罩揭示                       | 只露出一部分            | 「由左往右揭開」                        |

## 運動來源與程序手法

說出「動作由什麼產生」，就決定了作品是手調、算出來，還是模擬出來的；依地圖二的五種來源分組。

| 術語                            | 意思                                             | 描述範例                         |
|---------------------------------|--------------------------------------------------|----------------------------------|
| 關鍵影格 Keyframe               | 人定的姿勢或數值                                 | 「3 個關鍵影格：0、0.5、1.2 秒」 |
| 補間 Tween ／ In-between        | 軟體自動補出中間格                               | 「中間交給補間」                 |
| 表達式 Expression               | 用一小段程式控制屬性                             | 「旋轉 = 時間 × 90」             |
| 依序號錯開 Index offset         | 每個複製品依編號延遲                             | 「第 n 個延遲 n × 0.05 秒」      |
| 振盪 Oscillation                | 用正弦波來回擺動                                 | 「上下 20 px、週期 2 秒」        |
| 雜訊 Noise（Perlin ／ Simplex） | 平滑的隨機變化                                   | 「位置加一點低頻 Perlin 雜訊」   |
| 分形雜訊 fBm                    | 多層雜訊疊加，像山或雲                           | 「4 層 fBm 做地形起伏」          |
| 捲曲雜訊 Curl noise             | 像流體般迴旋、不會擠在一起                       | 「粒子沿 curl noise 迴旋」       |
| 域扭曲 Domain warping           | 用雜訊扭曲雜訊，像大理石或煙                     | 「背景做大理石般的域扭曲」       |
| 參數曲線                        | 由公式畫出的軌跡：利薩如、玫瑰線、萬花尺、環面結 | 「沿 (3,5) 環面結移動」          |
| 極座標 Polar                    | 用角度與半徑描述形狀與運動                       | 「形狀用 r(θ) 內插變形」         |
| 數值映射 Remap                  | 把一個範圍換算到另一個範圍                       | 「音量 0–1 映射成縮放 100–130%」 |
| 隨機種子 Seed                   | 固定隨機結果，可重現                             | 「種子固定 42，每次算圖一樣」    |
| 剛體 Rigid body                 | 硬物碰撞、堆疊、彈開                             | 「字母掉落堆疊，再被重球砸散」   |
| 軟體 Soft body ／ 布料 Cloth    | 會變形的物體與布                                 | 「旗幟在風中飄」                 |
| 流體 Fluid                      | 液體或煙的流動                                   | 「墨水在水中擴散」               |
| 粒子系統 Particles              | 大量小點的發射與運動                             | 「每秒發射 5,000 顆」            |
| 群集 Flocking ／ Boids          | 鳥群魚群般的群體行為                             | 「點群像魚群繞圈」               |
| 反應擴散 Reaction–diffusion     | 兩種物質互相反應長出紋理                         | 「Gray–Scott 珊瑚紋從字裡長出」  |
| 細胞自動機 Cellular automata    | 格子依鄰居規則演化                               | 「像生命遊戲般閃爍生長」         |
| 差分增長 Differential growth    | 曲線不斷伸長擠出皺褶                             | 「線條像珊瑚邊緣般捲曲生長」     |
| L 系統 ／ 碎形 Fractal          | 規則反覆展開，像植物或雪花                       | 「樹枝依 L 系統分岔長出」        |
| 反向運動學 IK ／ 綁定 Rig       | 拉末端、關節自動跟著動                           | 「拖手掌，手臂自動彎曲」         |
| 約束 Constraint                 | 鎖定關係，例如永遠看向某點                       | 「眼睛永遠看向游標」             |
| 音訊驅動 Audio-reactive         | 聲音的音量或頻段控制畫面                         | 「低頻越大，圓越大」             |
| 資料驅動 Data-driven            | 數值來自資料                                     | 「柱子高度來自每月營收」         |
| 捲動驅動 Scroll-linked          | 捲動位置當時間軸                                 | 「捲到一半時插畫組裝完成」       |
| 手勢驅動 Gesture-driven         | 拖曳、捏合直接控制                               | 「放手後依甩動速度彈回」         |
| 狀態機 State machine            | 依狀態切換動畫                                   | 「待機、懸停、按下三種狀態」     |
